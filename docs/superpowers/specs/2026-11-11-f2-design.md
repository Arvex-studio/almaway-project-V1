# AlmaWay F2 — everyday Alpine Atlas

Owner explicitly delegates design choices, implementation and review; no additional design approval gate is needed. Work stays on frontend/f1-alpine-editorial, preserving F1 at 029ad2706a10dfc41a68d03850352730bf71e5e8 and Draft PR #6. Backend contracts, auth, migrations and user data are out of scope.

## Audit and references
Alpine Atlas: strong pine/ivory, image hierarchy, orange index and typography; oversized cover delays useful actions. Retain identity, reduce mobile titles to 30–34px and put search, image, title and save in the first viewport.
Field Journal: editorial serif, intimate photography and varied rhythm fit stories. Do not carry its oversized title or overlapping pictures into the feed; keep a consistent place attachment and action row.
Topographic Adventure: the third attachment is unavailable. Only the user's textual direction is available; original nongeographic contour artwork is appropriate for empty/Journey states, never a route map.
F1: no functional search; 4/5 existing geographic objects hidden from Explore; unavailable ideas dominate; missing map key blocks primary task; fabricated profile metrics distract even when labeled; saved map links lose selected identity; social absent. Old local production process has stale asset URLs (unstyled capture), so audit uses immutable deployed F1.

## Approaches (designer decision under delegated autonomy)
1. Social-first Home: compelling but displaces immediate geographic exploration.
2. Combined places/stories Explore: fewer tabs, mixes two browsing intents and filter models.
3. Dedicated Journal, selected: Explore / Journal / Map / Saved / Profile; Plan remains a contextual tool from places, Saved and Profile. Five stable destinations, map central, direct photo→place→map path.

## Product system
Self-hosted variable Manrope for Cyrillic UI/headings; literary Lora for journal titles only. OFL licenses bundled. Pine #123b30, ivory #f6f3eb, teal #087d7c, burnt orange #b83b16. 44px controls, legible 14–16px body, 8px spacing rhythm, restrained 8–16px corners, no glass/gradients. Desktop max-width split content, mobile compact single column. Motion 160–220ms and reduced-motion alternative.
Explore gets actual catalogue search, category filters, compact photo feature and useful directory. Place detail frontloads name/photo/map/save, then verified description/source, unknown conditions, plan and linked stories. Missing photography is explicitly absent.
Journal is an explicitly labeled interactive demo. Editorial sample is not a real person's post; no invented likes/comments/followers. Likes and saved stories reflect only local interactions. Composer: local photo selection with size/type validation, preview, place association, caption, local draft save, discard/close; nothing uploaded or published. Comments local only. Profile is signed-out guest with real session save count and demo journal link, no fabricated achievements. No persistence or backend changes.
MapLibre stays. Configured MapTiler Outdoor remains primary; absent key uses public OpenFreeMap Liberty, with automatic source attribution, no offline download, no service guarantee. Selection, clustering, filters, layers, geolocation and true sourced demo segment preserved. Failures retain retry/catalogue.
