# AlmaWay F2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Turn Alpine Atlas into a useful mobile exploration and demo journal app.
**Architecture:** Existing AppShell, MapLibre and session provider; isolated journal context; shared visual tokens. No backend changes.
**Tech Stack:** Next16, React19, TypeScript, MapLibre, pnpm10.34.3, Node22.
**Spec:** docs/superpowers/specs/2026-11-11-f2-design.md

## Global Constraints
Preserve F0 identities, F1 source and PR6 draft. No auth/database/backend changes. No production deployment. Honest demo, licensed media, true geography. 44px targets, reduced motion, Cyrillic.

## Review Focus
1. Search with whitespace/empty/no match must reset/filter clearly.
2. Composer invalid files and close/reopen must not lose draft or leak object URLs.
3. Journal interactions survive client navigation, but clearly reset on reload.
4. Map provider unavailable must offer retry and usable catalogue; selected identity remains stable.
5. Narrow/landscape views, keyboard dialogs and long captions must remain usable.
