## Ошибки среды и восстановление

- Первый запуск pnpm использовал системную версию 11. Для воспроизводимой проверки запущен проектный pnpm 10.34.3. После отказа интерактивного переустройства node_modules в non-TTY установка успешно завершилась с CI=true.
- Windows-обёртка Vercel потеряла разделитель аргументов, а `env run` не выдал значение публичной переменной для локальной сборки. Для локальных снимков использована публичная конфигурация уже запущенного Guard; значение не печаталось. Загрузка карты подтверждена также отдельно на Vercel. Для проверки защищённого URL потребовался фактический сеансовый cookie. Он использовался только в памяти. Изменений переменных Vercel в этой сессии не было.
- Первые попытки съёмки попали в запуск сервера и в состояние, где озеро находилось вне маленькой карты. Снимки пересняты после готовности, с одинаковым шагом масштаба. На широком экране дождались прорисовки тайлов перед сохранением. Предварительный dev-прогон вывел предупреждение о медленной ФС и закрытом потоке; итоговый полный прогон завершился без падений.
- Notion автоматически нормализовал два упоминания задач в сессионной странице. Проверены принадлежность записи Control Room и итоговые поля существующих задач.
